# 项目映射

## 目录关系

以下路径均相对仓库根目录。

| 位置 | 职责 |
| --- | --- |
| AGENTS.md | 本仓库长期协作与读写规则 |
| PROJECT_INDEX.md | 文档职责及条件路由 |
| README.md | 项目用途、基本使用及入口 |
| docs/context/ | 当前状态、映射、操作、决策和风险专题 |
| docs/context/history/ | 有价值的历史过程及其索引 |
| .gitignore | 本地中间文件、产物和认证文件的忽略规则 |

work/ 与 outputs/ 是忽略规则预留的本地产物位置，不承诺目录已存在；不作为项目事实来源。

## 版本与远端

- 本地版本管理：Git 仓库，初始分支为 main。
- GitHub 公共仓库：[project-context-foundation](https://github.com/Lyz30919235/project-context-foundation)，已通过匿名 API 确认为 Public。
- 远端名称：origin；地址为上述仓库的 HTTPS Git 地址。实际配置以 Git 元数据为准，核验范围见 [NOW](NOW.md#核验与证据)。
- 当前提交、未提交改动和远端分支状态应实时查询，不在多份文档维护哈希副本。
