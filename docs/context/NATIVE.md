# Windows 原生版

## 技术与范围

Windows 电脑版使用 Godot 4.7.2 稳定标准版与 GDScript，Compatibility 渲染器；Godot 工程位于 [godot](../../godot/project.godot)。Python 仅用于构建工具和地图处理，运行免安装包不需要编辑器、Python 或 Node.js。

用户于 2026-11-07 确认：电脑版优先、保留手绘风格、只去纸张底纹横线、平滑自由移动并保留点击寻路。本轮先交付 Windows 64 位压缩包，网页保留旧版。人工试玩按用户后续明确选择交由其自行验收。

## 数据与去线

- 原始照片与 [原图标注](../../src/map.annotations.json) 继续作为来源；网页版生成资源保持原版本。
- [原生地图生成器](../../scripts/prepare_native_map.py) 从原图颜色与长横线几何特征拟合纸张底纹，保留深色墨线及跨越底纹的墙体笔画，再生成电脑版画面与碰撞。
- 当前识别出 31 组候选曲线，清除 31,058 个误识墨线像素；这一数量是候选拟合结果，不等同于纸张格线条数。
- 复查旧版 33 处道路校准，取消已冗余的 15 处，保留仍需连接的 18 处。索引与处理参数以 [processing-report.json](../../godot/assets/map/processing-report.json) 为准。
- 纸张横线候选带之外的原有墨线在清理步骤中保持一致；物品文字清除和保留的道路校准另行处理，不将它们当成已确认原图开口。
- 地图版本包含去线后数据摘要，存档按地图版本核对。生成资源不手改；修改源标注或算法后重新生成并验证。

## 运行结构

- [rules.gd](../../godot/scripts/rules.gd)：星星、钥匙、门、传送、问号与胜利状态。
- [player.gd](../../godot/scripts/player.gd)：连续八方向运动、圆形扫掠碰撞、贴墙滑动及道路居中辅助。辅助在岔路附近关闭，且须有无遮挡连接。
- [navigation.gd](../../godot/scripts/navigation.gd)：走廊中心线图；键盘输入立即取消点击路径，自动行走按剩余时间消耗多个小路点，避免路点密度限制速度。
- 地图分为 88 个静态边界碰撞区块；导航当前含 57,071 个节点，画面、导航与碰撞来自同一份去线数据。
- 相机提供跟随、边界约束、拖动、缩放、全图与定位；失焦暂停并释放方向状态。中文字体随包提供。
- 原生存档使用 Godot user:// 下独立文件，正常游戏与开发 QA/包验证使用不同文件，不自动读取网页存档。

## 验证边界

规则/移动回归、窗口及存档集成、真实圆形碰撞控制器的全图推进，以及导出后独立进程检查均有独立入口，见 [RUNBOOK](RUNBOOK.md#业务运行与验证)。执行结果统一记录在 [NOW](NOW.md#核验与证据)。

全图测试使用真实 NativePlayer 控制器及静态边界物理碰撞，不以旧版像素位置更新代替；仍不等于用户真人通关。未确定的原图编号、钥匙2和终点位置继续见 [RISKS](RISKS.md#r3-地图标记与拓扑待核实)。
