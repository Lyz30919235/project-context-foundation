# Idea 调研与发展方法

## 适用范围

收到用户提供的 idea，或需要调研相近工作、判断差异与发展空间时，按当前问题读取本页相关部分。本页保存方法要求，不承载具体 idea 的调研结论。

## 判断原则

- 不追求“绝对原创”或“从未有人做过”的完美 idea，不因存在相似工作就过度防御性地否定方向。默认先尝试保留和发展用户的 idea。
- 已有方法在相关问题上的尝试，不意味着思路失去价值。判断重点是能否形成明确且有意义的新增价值，以及是否存在推进、完善或深化的空间。
- 有意义的差异可以来自解决现有方案的不足、改善体验、满足新的需求，或从新的视角重新组织问题、提出更有效的解决方案。差异需要说明受益对象、发生条件和实际影响。
- 想法尚不成熟时，具体指出可以怎样发展，不能仅以“已经有人做过”为由结束讨论。
- 优先发展不等于预设创新成立。核心问题、关键做法和主要价值确实高度重合、难以形成实质区分时，必须如实说明，不为保留 idea 强行制造创新性。

## 调研流程

1. 先准确还原 idea：明确要解决的问题、目标对象、核心做法、使用场景和预期价值。缺失信息标注待核实；只在影响后续判断时请求必要补充，不擅自替换用户的原始设想。
2. 系统查找最接近的案例、产品方案或研究：按问题、方法、场景及同义表述检索，不能只搜索 idea 名称。已有调研只有在对象和时效仍适用时才能复用；需要查证的当前能力应联网核实。
3. 深入理解相近工作的核心思路、具体做法、关键步骤、适用场景、前置条件和局限。优先使用原始论文、官方文档、公开实现或其他直接证据，不能仅凭名称、简介、摘要或表面相似认定重复。
4. 记录支持比较的必要来源、版本或日期，并区分来源已证实的事实、据此作出的推断和仍待核实的信息。不能为突出差异而编造现有方案的不足；没有找到先例也不能证明“从未有人做过”。
5. 按下列维度比较最接近的工作；证据不足或相互冲突时再扩大检索范围。覆盖足以支持当前结论的主要相近路径后停止，不把系统调研变成无边界遍历。
6. 基于真实比较给出新增价值说明及验证办法。若实质重合，转入调整分析；调整后仍需重新与最接近的工作比较。

## 差异比较

| 维度 | 需要回答的问题 |
| --- | --- |
| 核心问题与目标对象 | 解决的是否是同一个问题？谁受益？需求及约束是否存在实质差别？ |
| 关键做法 | 流程、机制、交互、数据或技术路径具体如何运作？哪些差别会改变结果？ |
| 适用场景 | 使用条件、前置成本及适用边界有什么差异？差异是否满足了实际需求？ |
| 主要价值 | 对效果、体验、效率、可及性或成本的改善是什么？与现有方案相比为何值得采用？ |
| 局限与代价 | 证据已确认哪些不足？本 idea 引入了什么代价？哪些只是待验证假设？ |

区分“做法看起来不同”和“产生了有意义的不同结果”。措辞变化、名称变化或技术组合本身不足以证明新增价值。

## 新增价值说明与验证

用一段清晰、有说服力的话说明：与哪些最接近的工作相比，我们具体新增了什么、推进了什么；这些差异在哪些场景对哪些对象有意义；哪些证据已支持判断，哪些价值仍需验证。不要把价值假设写成已证实的收益。

可按实际内容组织为：“与〔最接近的工作〕相比，这个 idea 在〔问题、做法或场景〕上新增或推进了〔具体差异〕，使〔目标对象〕有望获得〔实际价值〕。差异之所以有意义，是因为〔需求、限制或证据〕；尚待验证的是〔关键假设〕，可通过〔具体比较或实验〕检验。”

对每项关键价值提出可以执行的验证办法，至少写清：

- 价值假设：预期改善什么，以及在什么条件下成立。
- 对照基线：最接近的现有方案、现行流程或其他有依据的比较对象。
- 最小验证：原型、同任务比较、用户试用或实验的具体步骤、对象和所需数据。
- 判断依据：采用什么指标或观察判断有价值，什么结果会削弱或否定假设；可量化的成功标准应在执行前确定，缺少依据时标注待定，不虚构阈值。
- 成本与下一步：最低必要投入、主要限制，以及结果不同后分别怎样调整。

“进一步研究”“做个 MVP”不能单独充当验证方案；须说明要验证的具体价值及如何判断结果。没有具体 idea 时只保存方法，不伪造实验设计、数据或验证结果。

## 高度重合时的处理

只有在核心问题、关键做法和主要价值的实质比较支持结论时，才判断高度重合。明确列出重合的工作及证据，逐项解释重合在哪里、剩余差别为何不足以形成有意义的区分。

随后提出有依据的调整方向，例如聚焦未被充分满足的对象或场景、解决已证实的限制、改善关键交互与工作流程，或在新的约束下重组问题。说明每项调整试图新增什么价值、需要什么条件、如何验证。

调整不能只换名称、堆叠功能或强行声称创新。若目前没有足够依据建立差异，应明确说明当前判断及可能改变判断的证据，同时保留具体可探索的路径。

## 输出与记录

一次具体 idea 评估应按任务需要给出：

1. 对原始 idea 的准确理解，以及必要的待核实事项。
2. 最接近工作的实质比较与来源，包含具体做法、场景及局限。
3. 一段新增价值说明，区分已知事实与价值假设。
4. 对关键价值的具体验证办法。
5. 实质重合、局限和可发展或调整的方向；不能省略不利证据。
