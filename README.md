# map · 纸上迷宫

## 项目用途

把用户上传的手绘迷宫制作成可直接游玩的浏览器游戏。道路轮廓来自原图数字化，保留曲线、螺旋和主要地标；地图识别与局部校准范围见 [游戏设计](docs/context/GAME_DESIGN.md#识别与校准范围)。

游戏规则：收集全部星星后才能进入终点；传 n 到达传 n+1；钥匙打开对应编号的门；问号没有物品。当前重绘版包含 4 颗星星、5 把钥匙和 5 个传送点，钥匙保留，传5暂作最终落点。

## 基本使用

- 在线试玩入口及访问范围见 [配置与部署](docs/context/MAP.md#配置与部署)。

- 双击 [打开map.cmd](打开map.cmd)，或用浏览器打开 [map.html](dist/map.html)，无需安装依赖即可离线游玩。
- 方向键 / WASD 移动；点击道路会沿可通行路线行走。拖动查看地图，滚轮或双指缩放。
- F 查看全图，C 定位自己，空格暂停。页面还提供小地图、局部路线提示、原图对照和重新开始。
- 进度保存在当前浏览器的本地存储中；离线文件与在线站点的存档彼此独立。
- 开发预览、构建与测试命令见 [RUNBOOK](docs/context/RUNBOOK.md#业务运行与验证)。
