# 项目上下文基础文档

## 项目用途

本仓库建立一套供后续 AI 按需定位资料、正确写入信息并接续工作的基础文档。

当前建设对象是文档基础。业务项目名称、领域、功能、技术栈及实际使用场景尚未提供，均为待核实事项。

## 基本使用

1. 开始任务先确认适用的 [项目规则](AGENTS.md)，已有且仍有效的规则无需重复读取。
2. 需要定位资料时使用 [项目索引](PROJECT_INDEX.md)，只进入当前任务相关的文件和章节。
3. 接续工作时定位 [当前状态](docs/context/NOW.md) 中相关目标、阻塞和下一步，再按证据入口核对所需事实。
4. 写入前确认该类信息的权威位置，读取目标部分及必要上下文，定点修改并验证本次改动。
5. 完成一个改动批次后，按 [运行手册](docs/context/RUNBOOK.md#git-提交与公共同步) 提交并同步至公共仓库。

本仓库尚未定义业务安装、启动、构建或测试命令。相应方法需获得真实实现和运行证据后补充。
